# 2026 화담집 편집실 — 외부 OCR 방식 미리보기

Google 로그인이나 Apps Script 설치 없이 사진앱/외부 OCR에서 추출한 글을 붙여넣는 방식입니다.

- 입력 순서: 목차 / 작성자 학번·이름 / 원고 제목 / 담당 편집위원.
- iPhone 사진앱의 텍스트 선택, 지원되는 갤럭시 갤러리의 텍스트 추출 사용 안내.
- i2OCR 한국어 페이지와 OnlineOCR를 별도 창으로 여는 바로가기. 자동 업로드나 자동 연동은 하지 않습니다.
- 이 사이트에는 OCR 엔진이나 OCR 예시 출력이 없습니다. 실제 글자 인식은 선택한 사진앱/외부 서비스에서 수행합니다.
- 사진은 교정용 미리보기와 기기 내 압축에만 사용하며 서버로 전송하지 않습니다.
- 원고는 localStorage, 미제출 초안은 sessionStorage에만 보관합니다. 다른 기기의 관리자에게 제출되는 공동 저장 서비스는 아닙니다. 관리자 체험도 같은 브라우저의 데이터만 봅니다.
- 외부 서비스는 이 실행 환경의 네트워크 정책(403) 때문에 실제 접속·가입 요구·한국어 손글씨 인식률을 검증하지 못했습니다. 실제 학교 기기에서 시험해야 합니다. 외부 업로드 시 이름·학번을 가리고 본문만 사용하세요.

모바일 390px, PC 1280px에서 실제 Chromium으로 네 줄 입력 배치, 학번과 이름의 같은 줄 배치, 입력·제출, 학번 검색, 목차·상태 수정, 원고 복사 순서와 문단 보존, 새로고침 후 저장 유지, 가로 넘침 없음, JavaScript 오류 없음을 확인했습니다.

기존 Apps Script 구현은 별도 원본으로 보관되어 있으며, 이 미리보기에 연결되지 않습니다.
