# 검증 기록

검증일: 2026-11-16 (한국시간)

## 실제 수행한 자동 점검

- Node.js에서 Code.gs와 Index.html의 JavaScript 구문 분석 성공.
- `npm test`: 서버 테스트 11개 통과. Google 서비스는 테스트용 모의 구현.
  - 학교 도메인 외부 및 확인 불가능한 사용자 거부
  - 편집위원의 관리자 전체 조회·수정 거부, 세션의 계정 귀속
  - 동일 접수 번호 재시도 시 한 번만 저장, 쓰기 잠금 적용 확인
  - RAW 기록으로 수식형 문자열·빈 줄·줄바꿈 유지
  - 잘못된 목차·원고 길이·반·필수 값 거부
  - 관리자 목차·상태·본문 수정, 이전 버전 덮어쓰기 거부
  - 비밀번호 교체와 로그아웃에 따른 세션 무효화
  - 반복 로그인 추측 제한
  - Drive v3 이미지 가져오기 옵션, 성공·문서 읽기 실패 시 삭제 실행
  - 잘못된 이미지·초과 용량·허용 밖 페이지 번호 사전 거부
  - 시트 열 변경 시 쓰기 거부
  - Google 내부 오류를 한국어 일반 안내로 변환하여 식별자 노출 방지
- `npm run test:ui`: 실제 Chromium, 390px·768px·1280px 너비에서 각각 통과. google.script.run 응답만 모의 구현.
  - 로그인과 편집위원/관리자 화면 전환
  - JPG 압축 및 미리보기, OCR 텍스트를 기존 원고 뒤에 추가
  - 제출 오류 후 원고 유지, 재시도 시 동일 접수 번호 사용
  - 제출 성공 후 사진 정리와 중복 클릭 차단
  - HTML처럼 생긴 학생 제목이 실행되지 않고 텍스트로 표시
  - 관리자 목차·본문·상태 저장과 검색 결과 반영
  - 페이지 전체의 가로 넘침 없음, JavaScript 미처리 오류 없음
- 모바일 관리자 화면 캡처를 열어 확인하고 버튼 너비를 보완한 뒤 화면 테스트를 다시 통과함.
- 공식 Google 클라이언트 저장소의 Drive v3 Discovery 정의를 다운로드하여 `files.create`의 `ocrLanguage`, 미디어 업로드 지원, 삭제 메서드 존재 확인.

## 아직 실서비스에서 수행하지 않은 점검

이 작업에서는 학교 운영 계정의 Apps Script 프로젝트·시트·배포를 만들거나 실제 학생 사진을 전송하지 않았습니다. 따라서 다음은 성공했다고 주장하지 않습니다.

- 학교 Workspace 정책에 따른 사용자 이메일 제공과 OAuth 승인
- 실제 Google Drive 한국어 손글씨 인식 결과 및 인식률
- 실제 Sheets API 쓰기·조회와 Google LockService의 동시 실행
- Google 서비스 사용량 한도·캐시 조기 만료·시간 트리거 실행
- 실제 학교 계정의 `/exec` 접속 및 학생/관리자 권한
- 한글(HWP)의 기기별 클립보드·문단 스타일 반영

README의 배포 전 현장 점검표로 검증하세요. 테스트 프로그램은 설치용 코드(src)에 포함되지 않으며 Apps Script에 붙여넣지 않습니다.
