# 문장 탐험대

중학교 3학년 국어 성취기준 **[9국04-06] 문장의 짜임과 양상을 탐구하고 활용한다**를 위한 React 학습 웹앱입니다.

## 처음 실행하기

1. 컴퓨터에 **Node.js 22 이상**을 설치합니다. 이 환경에서는 Node.js 24로 확인했습니다.
2. 터미널에서 이 저장소 폴더로 이동합니다.
3. 아래 명령을 한 줄씩 입력합니다.

```bash
npm ci --cache /workspace/.npm-cache
npm run dev
```

개인 컴퓨터에서는 첫 번째 명령을 `npm ci`로 실행해도 됩니다. 터미널에 표시되는 주소를 브라우저에서 열면 됩니다. 서버를 종료하려면 터미널에서 **Ctrl+C**를 누릅니다. 회원가입, API 키, 데이터베이스는 필요하지 않습니다.

배포용 파일을 만들려면:

```bash
npm run build
npm run preview
```

`dist/` 폴더를 정적 웹 호스팅에 배포할 수 있습니다. 글꼴과 아이콘도 앱에 포함되어 있어 실행 중 외부 API에 의존하지 않습니다. 최초 설치에는 npm 패키지 다운로드가 필요합니다.

## 사용 방법

- **탐험 홈 / 학습 지도**: 모든 단계는 순서와 관계없이 시작할 수 있습니다.
- **1단계**: 주어, 서술어, 목적어, 보어, 관형어, 부사어, 독립어 찾기 7개 활동.
- **2단계**: 홑문장·겹문장 판별 5개 활동.
- **3단계**: 대등·종속 연결과 의미 관계 탐구, 카드 연결 5개 활동.
- **4단계**: 명사절·관형절·부사절·서술절·인용절 탐구 6개 활동.
- **5단계**: 카드 조립, 문장 변환, 자유 작문 5개 활동.
- **최종 도전**: 위 내용의 핵심 10문제. 완료하면 최고 정답 수를 저장합니다.
- **카드**: 아래 카드를 위 빈칸으로 드래그하거나 누르면 추가됩니다. 위에 놓은 카드를 누르면 다시 빼낼 수 있습니다. 터치 기기에서는 누르기를 사용하세요.
- **자유 작문**: 문장 입력 → 예시와 비교 → 조건 충족 여부 자기 점검 → 완료. 자동 문법 채점이 아니며, 교사가 문장을 함께 검토할 수 있습니다.
- **점수**: 각 활동 최초 해결 시 10점, 연속 정답 3회부터 최초 해결 시 5점 추가. 이미 해결한 문제의 반복 정답에는 점수가 없습니다. 자유 작문은 자기 점검 완료 시 10점입니다.
- **배지**: 한 단계의 모든 활동을 해결하고 그 단계의 마지막 활동까지 마치면 받습니다.
- **오답 노트**: 틀린 문제의 해설을 확인하고 다시 풀 수 있습니다. 정답을 맞히면 오답에서 제거됩니다.

## 교사용 기능

왼쪽 메뉴의 **교사용 공간**에서 수업 모드를 켜면 본문과 문제 글씨가 커집니다. 상단 **학습 지도**에서 활동을 시작하고, **수업 모드 종료**로 돌아오세요. 반응형 화면이라 PC·태블릿·스마트폰에서도 사용할 수 있습니다.

**JSON 편집**에서 문항, 선택지, 정답, 해설과 카드 내용을 바꿀 수 있습니다. 변경은 이 브라우저에만 저장됩니다. 정답 번호 `answer`는 0부터 시작합니다. 기존 `id`, `stage`, `type`과 문항 수를 유지해야 하며, 저장할 때 데이터 구조를 검사합니다. 편집기에서 기본 문제를 불러온 뒤 저장하면 기본 내용으로 복원됩니다. 수정 후에는 교사가 정답과 문법을 다시 검토해 주세요.

원본 데이터는 `src/data.js`에 있습니다.

```js
{
  id: '2a', stage: 2, type: 'choice',
  prompt: '이 문장은 어떤 문장일까요?',
  sentence: '나는 어제 도서관에서 책을 읽었다.',
  options: ['홑문장', '겹문장'],
  answer: 0,
  explanation: '주어와 서술어의 관계가 한 번 나타나는 홑문장이에요.'
}
```

문법 예시는 학교 문법의 통상적인 문장 성분·절 분류를 따릅니다. 생략된 성분과 절의 역할을 해설에 밝혔으며, 예를 들어 ‘되다’ 앞의 ‘의사가’는 보어, ‘코끼리는 코가 길다’의 ‘코가 길다’는 서술절로 다룹니다. 부사절은 학교 문법의 ‘-게’ 절 분석을 따릅니다.

## 학습 기록과 개인정보

점수·정답 이력·오답·배지·작문·최종 도전 최고 기록은 브라우저 `localStorage`에 보관합니다. 별도 서버로 전송하지 않습니다. 같은 브라우저를 사용하는 학생들은 기록을 공유하게 되므로, 공용 기기는 결과를 내보낸 뒤 초기화해 주세요. 기록은 자동으로 다른 기기에 동기화되지 않으며, 브라우저 데이터를 지우면 사라집니다.

**학습 기록 → 학습 결과 내려받기**로 JSON 파일을 저장할 수 있습니다. 교사는 학생들이 내보낸 파일을 수집해 결과를 확인할 수 있습니다. 서버 기반 학급 통계와 파일 재가져오기는 포함하지 않습니다.

## 검증

```bash
npm test
npm run build
```

데이터 테스트는 단계별 문항 수, 카드 정답의 구성, 최종 도전 10문항, 오답 재도전, 중복 점수 방지와 콤보 보너스를 검사합니다. Chromium에서 실제 정답·오답 제출, 오답 복습, 기록 유지, 카드 조립, 작문 자기 점검, 교사용 편집·수업 모드, 최종 10문제와 모바일 메뉴 및 가로 넘침도 확인했습니다.

## 구성

- `src/main.jsx`: 화면, 활동, 교사용 편집과 로컬 저장
- `src/data.js`: 개념·문항·해설·점수 처리
- `src/styles.css`: Tailwind CSS와 반응형 디자인
- `tests/data.test.js`: 콘텐츠 구조와 점수 동작 검증
